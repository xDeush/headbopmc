# headbopmc

Make Minecraft skin "headbop" animations for TikTok edits, right in the browser.

- Type a Java player name (or upload a skin PNG)
- Pick a look from the preset carousel. Every preset shows a live thumbnail of your own skin
- Tweak beat, camera, pose, light, background and effects from the tool rail
- Record a perfectly looping clip as MP4 / MOV / WebM in 9:16, 1:1 or 16:9

Everything lives in one `index.html`. To host on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

Rendering by [skinview3d](https://github.com/bs-community/skinview3d). Skins from minotar.net (mc-heads.net as fallback).
